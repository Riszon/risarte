# Mensagem para pedir os dados do cadastro (Risartano novo)

Texto pronto para enviar a quem vai ser cadastrado no riSZon. Criado a pedido
do dono em 20/09/2026.

**A lista abaixo é a do formulário de cadastro** (`/risartanos/novo`), não uma
lista de boas intenções: cada item é um campo que o sistema exige para liberar
o acesso. Se o formulário mudar, **mude este texto junto** — pedir um dado a
menos faz a pessoa ser procurada duas vezes, e pedir um a mais é dado pessoal
coletado à toa.

**O que a pessoa NÃO envia** (quem preenche é a Risarte): unidade, função e
regime de contrato (CLT, PJ, Estagiário(a), Autônomo(a)).

**Dentista:** peça também as **especialidades** — o sistema usa isso para
sugerir o profissional certo em cada sessão.

**Depois do cadastro:** o acesso nasce com o **riSZon Treino** liberado e o
sistema real fechado; o real é liberado quando o treinamento termina (ver o
manual, seção 2.6).

## Por que cada pedido está aí

| Pedido | Por que o sistema precisa |
|---|---|
| Nome completo, CPF, nascimento | Identificam a pessoa; o CPF impede cadastro em duplicidade na rede |
| Como prefere ser chamado(a) | É o nome que a equipe vê nas telas |
| Gênero e estado civil | Campos obrigatórios da ficha; cônjuge só é exigido em casado(a)/união estável |
| WhatsApp | Contato do dia a dia |
| **E-mail** | **Vira o login.** E-mail que a pessoa não acessa = pessoa sem como recuperar a senha |
| Endereço completo | Ficha de RH |
| Foto (opcional) | Aparece na ficha e na lista; ajuda a equipe a se reconhecer |
